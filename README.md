# 📊 Real-Time Social Media Analytics Dashboard

## 🚀 Project Overview
This project performs real-time sentiment analysis on Twitter data and visualizes insights using a Streamlit dashboard.

## 🔧 Technologies Used
- Python
- Pandas
- Streamlit
- Machine Learning
- Git & GitHub

## 📂 Project Structure
dashboard/ → Streamlit UI  
src/ → Data preprocessing & sentiment analysis  
streamer/ → Real-time tweet streaming  
data/ → Dataset files  

## ▶️ How to Run

1. Install dependencies:
pip install -r requirements.txt

2. Run streamer:
python streamer/streamer.py

3. Run dashboard:
streamlit run dashboard/app.py

## 📈 Features
- Real-time tweet streaming
- Sentiment classification
- Live dashboard visualization
- Tweet counter updates
